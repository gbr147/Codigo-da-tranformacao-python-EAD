Este repositório contém uma coleção de programas práticos desenvolvidos para consolidar os fundamentos da programação em **Python 3**. O objetivo principal foi aplicar operadores aritméticos, estruturas condicionais de tomada de decisão (`if-elif-else`) e loops de repetição (`while`).

## 🚀 Desafios Incluídos

### 1. Operadores Aritméticos Básicos
Desenvolvimento de scripts simples para realizar e exibir as operações matemáticas fundamentais:
* **Soma** (`+`)
* **Subtração** (`-`)
* **Multiplicação** (`*`)
* **Divisão** (`/`)
* **Resto da Divisão / Módulo** (`%`)

### 2. O Maior Número
Um programa focado em tomada de decisão que solicita dois números ao usuário, faz a comparação lógica e imprime na tela qual deles é o **maior**, utilizando a estrutura condicional `if`.

### 3. Classificador de Idades
Um script que recebe o ano de nascimento ou a idade atual de uma pessoa e a categoriza em uma das quatro fases da vida, utilizando uma estrutura encadeada de `if-elif-else`:
* **Criança**
* **Adolescente**
* **Adulto**
* **Idoso**

### 4. 🏆 Desafio Extra: Menu Interativo de Calculadora
Construção de uma aplicação interativa via terminal que simula uma calculadora real. O programa utiliza um loop controlado (`while True`) para exibir um menu contínuo onde o usuário pode:
* Escolher a operação de **Soma**.
* Escolher a operação de **Subtração**.
* **Sair** do programa, encerrando a repetição apenas quando desejar.

## 🛠️ Conceitos Praticados

* **Manipulação de Variáveis e Tipos de Dados:** Entrada de dados do usuário com `input()` e conversão de tipos com `int()` e `float()`.
* **Estruturas Condicionais:** Fluxos de decisão limpos e eficientes com `if`, `elif` e `else`.
* **Estruturas de Repetição:** Controle de loops com `while` e interrupções seguras de código.
